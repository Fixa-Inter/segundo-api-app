## ✨ Visão geral

A API reúne os contratos consumidos pelo aplicativo Android e coordena os módulos operacionais de manutenção, identidade, equipamentos e notificações.

## 🚀 Funcionalidades

- Cadastro e autenticação tradicional ou com Google
- Renovação, logout e recuperação de senha
- Gestão de equipamentos, categorias, marcas e modelos
- Gestão de eventos, notificações e dispositivos
- Gestão de solicitações e ocorrências
- Gestão de ordens de serviço e tarefas
- Gestão de observações de conclusão
- Consulta e recomendação de técnicos
- Gestão de competências e perfil
- E-mails, notificações Firebase e autorização JWT
- Health check e documentação OpenAPI

## 🧰 Tecnologias

| Área | Tecnologias |
| --- | --- |
| **Backend** | Java e Spring Boot |
| **APIs** | Spring Web MVC |
| **Segurança** | Spring Security e JWT |
| **Persistência** | Spring Data JPA e PostgreSQL |
| **Apoio** | Redis e SMTP |
| **Notificações** | Firebase Admin |
| **Mapeamento** | MapStruct e Lombok |
| **Build** | Maven e Docker |
